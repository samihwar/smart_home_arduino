# Smart Home Arduino Project

This project demonstrates a smart home system built using Arduino technology.  
It integrates various sensors and actuators to automate and control home appliances, enhancing convenience and energy efficiency.

<img src="https://github.com/user-attachments/assets/49d92ae6-7fa0-4150-96cd-037b78627160" alt="Smart Home Setup" width="500"/>
  
## Features

- Automatic lighting control based on ambient light levels.
- Temperature monitoring and fan control for climate regulation.
- Touchscreen interface for user interaction.
- Remote access capabilities for monitoring and control.

## Hardware Components

- Arduino Uno R3
- TFT9341 Touchscreen Display
- DHT11 Temperature and Humidity Sensor
- LDR (Light Dependent Resistor)
- Relay Modules
- Various actuators (e.g., fans, lights)

## Setup Instructions

### 1. Hardware Assembly

- Connect the DHT11 sensor to the Arduino for temperature and humidity readings.
- Integrate the LDR to detect ambient light levels.
- Attach the TFT9341 touchscreen for user interface.
- Connect relay modules to control external devices like lights and fans.

### 2. Software Installation

- Install the Arduino IDE from the [official website](https://www.arduino.cc/en/software).
- Download and install necessary libraries:
  - Adafruit_GFX
  - Adafruit_TFTLCD
  - DHT sensor library
- Clone this repository:
  ```bash
  git clone https://github.com/samihwar/smart_home_arduino.git
  ```
### 3.Uploading the Code

- Open smart_home_arduino.ino in the Arduino IDE.
- Select the correct board and port from the Tools menu.
- Upload the code to the Arduino board.
